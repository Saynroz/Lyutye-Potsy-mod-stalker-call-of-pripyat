> ⚠️ \*\*МОД ТОЛЬКО ДЛЯ ВЗРОСЛЫХ (18+)\*\*

>

> Содержит нецензурную лексику, чёрный юмор, алкогольную тематику, грубые шутки, насилие и другие материалы, не предназначенные для детей.



\# 🗿 S.T.A.L.K.E.R.: ЛЮТЫЕ ПОЦЫ



> \*\*Зона. Припять. Семки. Лавэ. Похмелятор.\*\*



\*\*«Лютые Поцы»\*\* — юмористический мод для \*\*S.T.A.L.K.E.R.: Зов Припяти\*\*, превращающий Зону в место, где сталкеры делят хабар, гопники требуют семки, Мрази крысят артефакты, а главный вопрос после выброса — где достать рассол.



Это \*\*пародийный фанатский мод\*\*, созданный ради чёрного юмора, абсурда и максимально тупых ситуаций.
